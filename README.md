# CodeAlpha Internship – CAD Drafting Tasks

**Submitted by:** Abdul Wahab Shaikh

This repository contains my drafting and 3D modelling work for the CodeAlpha internship.

## Contents

| # | Folder | Work | Files |
|---|--------|------|-------|
| 1 | `01_Floor_Plan` | 2D ground floor plan of a residential house (scale 1:50, sheet A3, 10500 x 8000 mm external, 84.0 m² built-up area) | `Floor_Plan.dxf`, `Floor_Plan.pdf` |
| 2 | `02_Flange_Drawing` | 4-hole pipe flange, front section, side and top views (scale 1:1, sheet A3, mild steel) | `Flange_Drawing.dxf`, `Flange_Drawing.pdf` |
| 3 | `03_Staircase_3D` | 3D model of a straight staircase with landing (12 risers x 170 mm, treads 270 mm, width 1100 mm) | `Staircase_3D.dxf`, `Staircase_3D.obj`, `Staircase_3D.mtl`, `Staircase_Render.png` |

## How to view the files

- **PDF files** open in any PDF viewer.
- **DXF files** open in AutoCAD and other CAD software.
- **Staircase_3D.obj** opens in any 3D viewer (keep `Staircase_3D.mtl` in the same folder so the materials load).
- **Staircase_Render.png** is a preview image of the 3D model.
